# HT0.5 Live

Mobile-friendly live football fixtures page using API-Football.

## Deploy to Vercel
1. Upload the contents of this folder to a GitHub repository (the `api` folder must be at the repository root).
2. Import the repository in Vercel.
3. In Project Settings → Environment Variables, add `APIFOOTBALL_KEY` with your API-Football key for Production (and Preview if needed).
4. Redeploy.
5. Open the Vercel deployment URL and tap “刷新全球比赛”.

Do not put the API key in HTML, JavaScript, GitHub, or chat.
