HT0.5 Live — API-Football 接入起步包（iPhone 浏览器版）

包含：
- index.html：手机适配的实时比赛列表界面
- api/live.js：服务端代理全球实时比赛列表
- api/match.js：按需获取单场统计
- vercel.json：Vercel 函数配置

目前功能状态：
- 已写好 API 请求代理代码，但尚未部署到公网，也没有配置用户 API Key。
- 网页不会直接暴露 API Key；Key 应只存放在部署平台的环境变量。
- 已接入的数据字段：比赛列表、联赛、球队、比分、比赛状态/分钟；单场统计按需请求。
- 未实现历史数据训练、概率模型验证或实时赔率映射，因此当前不显示“真实概率”和投注建议。
- 危险进攻通常不是该统计接口的标准字段，界面会明确标为暂无。
- 免费计划公开额度：100 次请求/天、10 次请求/分钟（以账户当时显示为准）。每次列表刷新消耗一次请求；每次单场统计通常额外消耗一次请求。缓存可能降低重复调用，但不能保证完全不计数。

部署步骤（电脑或手机均可，电脑操作更方便）：
1. 注册 API-Football： https://www.api-football.com/ ，申请 Free 计划并在账户后台取得 API Key。
2. 把此 ZIP 解压后，将整个文件夹作为项目上传到 GitHub 仓库。
3. 在 Vercel 创建项目并导入该 GitHub 仓库。
4. 在 Vercel 项目 Settings → Environment Variables 新增：
   Name: APIFOOTBALL_KEY
   Value: 你的 API-Football Key
   不要把 Key 写进 index.html、公开代码或聊天。
5. 重新部署（Redeploy）。
6. 打开 Vercel 给出的真实项目网址，在 iPhone Safari 中使用。打开网页后点击“刷新全球比赛”。
7. 点某场比赛的“加载这场的统计”查看射门、射正、红牌等可用字段。

重要限制：
- 这个 ZIP 不包含 API Key，也没有替用户创建账号、GitHub 仓库或 Vercel 部署；所以尚无可直接访问的公网网址。
- 免费额度不适合全天高频自动刷新。当前默认手动刷新，避免持续轮询耗尽额度。
- API 数据可能延迟；不是所有赛事都有完整统计。
- 此版本只做真实数据接入，不训练或验证进球概率模型。不要把先前演示公式当成实测概率。
- “下半场至少再进一球”是明确的预测事件；赔率必须与该事件的结算规则一致，才能做公平赔率/EV 计算。普通全场大小球赔率不能直接替代。
