HT0.5 Live — API-Football 接入版（iPhone 浏览器）

项目文件：
- index.html：手机适配的实时比赛列表界面
- api/live.js：服务端代理全球实时比赛列表
- api/match.js：按需获取单场统计
- vercel.json：Vercel 项目配置

部署步骤：
1. 解压本压缩包。
2. 将解压后文件夹中的全部内容上传到 GitHub 仓库根目录；确认 api 文件夹与 index.html 同级。
3. 在 Vercel 导入该 GitHub 仓库。
4. 打开 Vercel 项目 Settings → Environment Variables。
5. 新增变量：Name 为 APIFOOTBALL_KEY，Value 为 API-Football 控制台中的 API Key。
6. 保存后进入 Deployments，执行 Redeploy。
7. 打开 Vercel 提供的项目网址，点击“刷新全球比赛”，再点击比赛卡片中的“加载本场统计”。

安全：不要把 API Key 写入 index.html、live.js、GitHub 公开仓库或聊天记录。只将密钥保存在 Vercel 环境变量中。若密钥曾经公开，请在 API-Football 后台轮换密钥。

限制：当前版本显示真实接口返回的比赛列表与可用统计，不含经过回测的进球概率模型，不提供保证盈利的投注建议。比赛统计可能因赛事覆盖或数据延迟而缺失。请求次数受 API-Football 套餐限制；避免频繁刷新。
